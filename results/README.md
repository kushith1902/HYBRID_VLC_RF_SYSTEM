# Experimental Results and Scientific Artifacts

This directory stores reproducible experimental results:
- `metrics_comparison.csv`: Tabulated baseline vs AI vs optimizer performance metrics.
- `ablation_results.csv`: Ablation study outputs.
- Figures (`.png`): High-resolution scientific figures (topology, throughput vs SNR, EE vs power, blockage impact, fairness, loss curves).
- Generated Markdown and text research reports.
